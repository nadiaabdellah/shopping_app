# Shopping App 🛍️

A simple Flutter shopping app that lets users browse products, search and filter them, and manage a cart and a favorites list.

> 🎓 **Educational project.** This app was created for learning purposes to practice Flutter and state management with Provider. It is **not** a real store, and no real purchases or payments are made.

> ⚠️ **Status: Work in progress.** The app is still under development, and its design and features are being improved and updated regularly.

## Overview
Shopping App shows a grid of products. Users can search by name, filter by category, open a product's details page, add items to the cart, and save favorites.

## What I'm Learning
- State management with Provider (`ChangeNotifier`)
- Building multi-screen Flutter apps (navigation, grids, lists)
- Search and category filtering
- Reusable widgets and clean UI structure

## Current Features
- Products grid with image, name, and price
- Search products by name
- Filter by category (All, Clothes, Shoes, Accessories)
- Product details page
- Add to cart and remove from cart, with a total price
- Add and remove favorites (heart icon) and a favorites page

## Tech Stack
- Flutter and Dart
- Provider (state management)

## Note on Data
The products shown in the app are **sample data for demonstration only**. Product images are loaded from online links.
